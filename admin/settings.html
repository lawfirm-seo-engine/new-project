텔레그램 알림, AI 생성, 네이버 카페 자동 업로드 연결을 설정합니다.

텔레그램 Chat ID

봇에게 메시지를 보낸 뒤 @userinfobot에서 본인 ID를 확인하거나, 그룹 채팅을 사용하는 경우 그룹 ID를 입력하세요. 그룹 ID는 음수(-)로 시작합니다.

값이 없으면 서버 환경변수(TELEGRAM_CHAT_ID)로 대체됩니다. 미설정 시에도 상담 접수는 GitHub에 저장됩니다.

OpenAI API 키

사건 초안 자동 생성(AI 드래프트)에 사용됩니다. 설정하지 않으면 규칙 기반 초안으로 대체됩니다.

모델: gpt-5.4-mini. 키가 없으면 기본 템플릿으로 생성됩니다.

네이버 카페 자동 업로드

네이버 Developers 앱에 카페 글쓰기 권한과 아래 콜백 주소를 등록한 뒤, 권한 연결을 한 번 승인하면 카페 원고·릴스 화면에서 게시글을 자동 업로드할 수 있습니다.

네이버 Developers 앱의 Callback URL에 이 주소를 그대로 등록하세요.

카페 주소의 gnlawfintech가 아니라 네이버 카페 내부 숫자 ID입니다.

자동 업로드할 게시판의 숫자 ID입니다.

게시글 URL 생성을 위해 사용합니다. 기본값은 gnlawfintech입니다.

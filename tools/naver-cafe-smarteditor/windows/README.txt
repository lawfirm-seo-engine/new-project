GNLAW SmartEditor for Windows

1. Extract the downloaded ZIP file.
2. Double-click Install.cmd.
3. Click the first login button in the installed GNLAW SmartEditor program.
4. Sign in to Naver and the gnlaw-criminal admin page in the opened Chrome window.
5. Click the login confirmation button in the GNLAW program.
6. From then on, click the automation start button and keep the program open.

The program can be installed on both home and office PCs. Run automation on only one PC at a time.

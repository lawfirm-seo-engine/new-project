GNLAW SmartEditor for Windows

1. Extract the downloaded ZIP file.
2. Double-click Install.cmd.
3. Click the first login button in the installed GNLAW SmartEditor program.
4. Sign in to Naver and the gnlaw-criminal admin page in the opened Chrome window.
5. Click the login confirmation button in the GNLAW program.
6. From then on, click the automation start button and keep the program open.

Before watching the queue, the automation start button verifies both the admin login and the saved Naver Cafe login. If either session has expired, run the first login step again.
The login confirmation step stores the browser session in the current Windows user's LocalAppData folder so it can be restored when automation starts.

For bulk work, select exactly 10 Reels images in each case row before registering the jobs. Local image selections are kept in that Chrome profile. If automation stops, use "등록한 대기열 불러오기" and resume from the first incomplete case on the same PC and Chrome profile.

The program can be installed on both home and office PCs. Run automation on only one PC at a time.
